## From prompt to live product

<Steps>
  <Step title="Describe the outcome">
    Start with the audience, the goal, and the essential pages or features. You do not need to choose a template or write code.
  </Step>
  <Step title="Review and refine">
    Kleap builds a first version that you can preview immediately. Continue the conversation to change the copy, layout, styling, or functionality.
  </Step>
  <Step title="Publish and grow">
    Publish to your `kleap.io` address, connect a custom domain, then add forms, a database, accounts, analytics, or integrations when you need them.
  </Step>
</Steps>

## Start with a clear prompt

You can begin with a rough idea. A little context helps Kleap produce a stronger first version.

<Frame caption="The English creation screen keeps the prompt, format, visibility, and Create action together">
  <img src="/images/tutorials/create-from-prompt.webp" alt="Kleap creation screen in English with Describe your idea and Create" />
</Frame>

<Tabs>
  <Tab title="Website">
    ```text
    Create a welcoming website for a neighborhood coffee shop.
    Include the menu, opening hours, location, and a contact form.
    Use warm colors and make it easy to read on mobile.
    ```
  </Tab>
  <Tab title="Web app">
    ```text
    Build a client portal for a small design studio.
    Clients should be able to sign in, view project milestones,
    download deliverables, and send feedback.
    ```
  </Tab>
  <Tab title="Internal tool">
    ```text
    Create an inventory dashboard for a three-location bakery.
    Show current stock, low-stock alerts, and a form for recording
    deliveries. Make each location easy to filter.
    ```
  </Tab>
</Tabs>

<Tip>
  Describe the result you want before prescribing the implementation. You can always refine individual sections and features after the first version appears.
</Tip>
